# Ticket Registry

Centralized operational state for ticket work. The `Status` column must always match the `status:` frontmatter of each `ticket.md` — the [[skills/lint]] skill reconciles the two. Statuses: `draft` · `blocked` · `ready` · `planned` · `in-progress` · `in-review` · `done` · `curated` · `cancelled` (see [[skills/shared/ticket-status-model]]).
